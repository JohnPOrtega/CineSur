Cobro de entradas

Dónde está: Se abre al reservar las butacas.

¿Para qué sirve?

Permite identificar al cliente, aplicar descuentos y cobrar las entradas.

¿Cómo se usa?

  1. Escriba el DNI del cliente y presione Buscar (sin DNI se cobra como consumidor final).
  2. Si el cliente no existe, puede darlo de alta como socio con Hacer socio.
  3. Revise subtotal, descuento y total.
  4. Elija el método de pago: Efectivo (indique con cuánto paga) o Tarjeta.
  5. Presione Confirmar venta. Se genera la entrada con su código.

Campos y botones

Cliente / SocioLos socios tienen descuento.
Paga conEn efectivo, el sistema calcula el vuelto.
CancelarAnula la operación y libera las butacas.

Tener en cuenta

El descuento de socio aplica desde la próxima compra si el cliente se hace socio en esta venta.
Las butacas reservadas que no se pagan se liberan solas cuando pasa la función.
