Restore de la base de datos

Dónde está: Se abre desde la pantalla de Integridad de Datos (botón RESTORE BD).

¿Para qué sirve?

Restaura la base de datos a partir de un backup (.bak).

¿Cómo se usa?

  1. Elija en la lista el backup a restaurar (se recomienda el más reciente).
  2. Si el archivo está en otra carpeta, presione Buscar otro...
  3. Presione Restaurar y confirme.
  4. Al terminar, vuelva a iniciar sesión.

Campos y botones

RestaurarReemplaza la base actual por la del backup.
CancelarCierra sin restaurar.

Tener en cuenta

Se pierden los datos cargados después de la fecha del backup.
CineSur - Ayuda en línea. Presione F1 en cualquier pantalla para ver la ayuda de esa pantalla.
