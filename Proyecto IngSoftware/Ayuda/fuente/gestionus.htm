Gestión de usuarios

Dónde está: Admin > Gestión Usuarios.

¿Para qué sirve?

Permite crear, modificar, activar o desactivar y desbloquear los usuarios del sistema.

¿Cómo se usa?

  1. Filtre la grilla con Activos, Todos o Bloqueados.
  2. Para crear: presione Crear, complete DNI, nombre, apellido, email y rol, y presione Aplicar.
  3. Para modificar: seleccione el usuario en la grilla, presione Modificar, cambie los datos y presione Aplicar.
  4. Para activar o desactivar: seleccione el usuario y presione Activar/Desactivar.
  5. Para desbloquear: seleccione un usuario bloqueado y presione Desbloquear.

Campos y botones

DNIIdentifica al usuario; no se puede repetir.
EmailDebe tener formato válido (nombre@dominio).
RolPerfil de permisos que tendrá el usuario.
Cancelar / SalirDescarta la edición en curso / cierra la pantalla.

Tener en cuenta

Al desbloquear, la contraseña vuelve a la de fábrica y el usuario debe cambiarla al entrar.
Cada operación queda registrada en la bitácora.
CineSur - Ayuda en línea. Presione F1 en cualquier pantalla para ver la ayuda de esa pantalla.
