Backup de la base de datos

Dónde está: Admin > Backup BD.

¿Para qué sirve?

Genera una copia de seguridad completa de la base de datos de CineSur.

¿Cómo se usa?

  1. Revise la carpeta donde se guardan los backups (por defecto C:\Backups43BO).
  2. Si quiere otra carpeta, presione Cambiar carpeta... y elíjala.
  3. Presione Generar Backup. El archivo .bak queda en la lista de backups disponibles.

Campos y botones

Carpeta actualDónde se guardan los backups. Debe ser una carpeta a la que SQL Server pueda escribir.
Backups disponiblesCopias ya generadas, la más nueva primero.
CerrarCierra la pantalla.

Tener en cuenta

Conviene hacer un backup antes de cambios grandes y guardarlo también fuera de la PC.
CineSur - Ayuda en línea. Presione F1 en cualquier pantalla para ver la ayuda de esa pantalla.
